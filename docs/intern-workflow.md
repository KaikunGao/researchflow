# 券商医药组数据分析实习生：工作流与痛点

> 本文按券商行业研究所医药组数据分析实习生的典型经历整理，用于指导 ResearchFlow 第二阶段的范围设计。
> 其中的团队配置、数据格式与任务频率是对典型情况的还原，与具体某家券商的实际细节可能有出入，后续以真实样例文件为准修正。

---

## 1. 工作背景

| 项目 | 典型情况 |
| --- | --- |
| 所在团队 | 研究所医药行业组：首席分析师 1 名、分析师 2–3 名、研究助理 1–2 名、实习生 1–2 名 |
| 覆盖范围 | A 股医药生物板块重点公司 30–50 家，按子行业分：化学制药、生物制品、医疗器械、中药、医疗服务 / CXO、医药商业 |
| 实习生定位 | 数据支持：维护财务跟踪底表、制作图表、整理同业对比、协助撰写财报点评的数据部分 |
| 工作节奏 | 平时按周更新；每年 4 月（年报 + 一季报）、8 月（中报）、10 月（三季报）为财报季，强度最高 |

## 2. 数据来源与格式

**主要来源**

1. **Wind 终端**：最主要的来源。常用两种方式：
   - Excel 插件函数（`w.wsd` / `=WSD(...)`）按指标和报告期拉取；
   - 「数据浏览器」或「财务报表」页面导出 Excel。
2. **Choice 金融终端**：部分团队用 Choice 替代 Wind，导出格式类似，但字段名和列顺序不同。
3. **巨潮资讯 / 交易所公告**：财报出来当天 Wind 可能还没更新，需要先从公告 PDF 里手抄核心数字。
4. **组内 Excel 底表**：历任助理和实习生维护的跟踪表，是实际工作中的"真相来源"。

**Wind 导出的典型格式（宽表）**

```
证券代码   证券简称   指标名称            2022-12-31   2023-03-31   2023-06-30   2023-09-30   2023-12-31
600276.SH  恒瑞医药   营业收入(元)        21,275,...   ...
600276.SH  恒瑞医药   归母净利润(元)      ...
600276.SH  恒瑞医药   销售费用(元)        ...
```

特点：
- 报告期横向排列，日期格式为 `YYYY-MM-DD`；
- 数值为累计口径（Q3 列是 1–9 月累计）；
- 单位是元或万元，写在指标名的括号里；
- 千分位、空值用 `--` 或空白表示；
- 多家公司堆叠在同一张表，或者一家公司一个 sheet。

**组内底表的典型格式**

- 一个 sheet 一家公司，或一个 sheet 一个子行业；
- 横向按报告期排列，上半部分是累计值，下半部分是手工公式算出的单季度值；
- 右侧或下方用公式计算同比、环比、毛利率、净利率、销售费用率、研发费用率；
- 不同人维护过，公式口径和格式并不完全统一。

## 3. 高频任务

### 3.1 财报季：更新一家公司（最高频、最赶时间）

公司出报当天的典型流程：

1. 从公告或 Wind 拿到最新报告期数据；
2. 粘贴到底表的新一列，核对单位与报告期；
3. 计算单季度值：Q2 单季 = 中报 − 一季报，Q3 单季 = 三季报 − 中报，Q4 单季 = 年报 − 三季报；
4. 计算同比、环比，以及毛利率、净利率、三费率、研发费用率；
5. 写财报点评的数据段落，例如：
   > 公司 2024 年实现营业收入 279.8 亿元，同比 +22.6%；归母净利润 63.0 亿元，同比 +46.8%；毛利率 86.2%，同比 +1.4 pct；销售费用率 XX%，同比 −X.X pct。Q4 单季度营收 XX 亿元，同比 +XX%，环比 +XX%。
6. 制作 3–4 张标准图：营收及增速、归母净利润及增速、毛利率 / 净利率趋势、费用率趋势；
7. 图表按研究所规范配色，标注"资料来源：Wind，XX 证券研究所"，发给分析师。

一家公司大约需要 30–60 分钟，财报季一天可能要处理 3–5 家。

### 3.2 同业对比表（每季度、深度报告前）

- 按子行业横向比较：营收增速、净利润增速、毛利率、销售费用率、研发费用率、存货周转、应收账款周转；
- 做成表格或分组柱状图，用于点评和深度报告的"行业比较"章节；
- 每次都要重新从底表里拉数、重新排版。

### 3.3 周报 / 月报的数据更新

- 板块行情回顾、估值表（PE / PB）更新；
- 需要行情数据，属于另一类数据源，暂不在 ResearchFlow 第一期范围内。

### 3.4 深度报告支持

- 整理公司 5–10 年的历史财务数据与结构拆分；
- 制作大量图表，对图表规范要求高。

### 3.5 数据核对

- 复核分析师模型中的历史数据是否与公告一致；
- 排查底表里的公式错误与口径不一致。

## 4. 痛点清单（按对实习生的影响排序）

| # | 痛点 | 具体表现 | 后果 |
| --- | --- | --- | --- |
| 1 | 更新底表的重复劳动 | 每家公司每个报告期都要导出、粘贴、核对单位 | 财报季加班主要来源 |
| 2 | 单季度拆分易错 | 手工公式差分，年报与三季报列错位就全错 | 需要反复复核，出错影响点评准确性 |
| 3 | 点评数据段落模板化 | 同一套话术换数字，手工填写易漏单位或正负号 | 时间花在抄数而非理解 |
| 4 | 图表重复制作 | 四张标准图每家公司重画，还要套研究所样式 | 每家公司 10–20 分钟纯机械操作 |
| 5 | 同业对比反复拉数 | 每次对比都要跨多个 sheet 取数、重排版 | 对比表更新滞后 |
| 6 | 口径不统一 | 不同人维护的底表公式不同，ROE、费用率口径不一致 | 横向对比失真，分析师质疑数据 |
| 7 | 数据源格式差异 | Wind 与 Choice 字段名、单位、排列不同 | 换数据源就要重做解析 |

## 5. 对 ResearchFlow 第二阶段的推导

把上面的任务和痛点对应到产品功能：

| 实习生任务 | ResearchFlow 功能 | 优先级 |
| --- | --- | --- |
| 更新底表 | 导入 Wind / Choice 导出文件，自动映射字段、统一单位、识别报告期 | P0 |
| 单季度拆分、同比环比 | 导入后自动计算单季度值、YoY、QoQ，并标注口径 | P0 |
| 点评数据段落 | 「财报速览」页一键生成数据段落文本 | P0 |
| 四张标准图 | 「财报速览」页自动生成标准图并导出 PNG | P0 |
| 同业对比表 | 公司对比页接入真实数据，支持导出 Excel | P1 |
| 口径统一 | 指标定义集中在后端，界面展示口径说明 | P1 |
| 周报估值表 | 需要行情数据，暂缓 | P2 |

对应需要新增的指标：销售费用率、管理费用率、财务费用率、存货周转天数、应收账款周转天数，以及所有指标的单季度版本。

## 6. 第二阶段默认假设（已按此实现，见 README「财报速览解决的四个痛点」）

在拿到真实样例文件之前，开发按以下假设进行，拿到样例后再修正：

1. 数据来源以 **Wind 导出的 Excel 宽表** 为主，兼容 Choice 的列名差异；
2. 导入文件为**累计口径**，系统负责拆分单季度；
3. 金额单位统一转换为**亿元**，比率统一为**百分比**；
4. 最高频的输出是**单家公司的财报点评数据段 + 四张标准图**，其次是**子行业同业对比表**。
