# ResearchFlow Frontend

Next.js（App Router）+ TypeScript + Tailwind CSS + shadcn/ui + Recharts。

```bash
npm install
cp .env.example .env.local   # 配置后端地址
npm run dev                  # http://localhost:3000
npm run lint                 # ESLint
npx tsc --noEmit             # TypeScript 检查
npm run build                # 生产构建
```

项目整体说明见仓库根目录的 [README.md](../README.md)。
